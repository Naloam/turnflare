# Turnflare v0.2.1 — Analytics & search

Download, open, and explore your Claude Code history. No Node.js setup is required for the desktop apps.

## New

- **Analytics workspace:** date presets, inclusive calendar ranges, project/model filters and main/subagent/combined scope. Totals, charts and exports use the same selected turns.
- **Activity heatmap:** 52 weeks of request activity; select a day to inspect it.
- **Daily, weekly and monthly tables**, model details and tool rankings with call counts, error rates and result size.
- **Personal budgets:** saved on your device, with 80%, 95% and exceeded-budget indicators for the selected range.
- **Session search:** IDs, projects, paths, branches and indexed message previews, plus model filtering. Literal `%` and `_` searches work.
- **One-click reports:** HTML, CSV, Markdown and JSON. Desktop apps use the native Save dialog; browser users get a file download.

All dates in Analytics are UTC; weeks start on Monday. The end date in the interface includes the entire day. Search indexes the first 200 characters of each message, not the full transcript. Budgets and costs are API-equivalent estimates, not subscription bills or official remaining quota. Unknown model pricing is marked rather than guessed.

## Signing status

These builds do not have a trusted Windows signing certificate or Apple Developer ID/notarization. Windows or macOS may ask for confirmation on first launch. On macOS, use System Settings → Privacy & Security → Open Anyway if the system blocks an app you downloaded from this release. Do not disable system security globally. `SHA256SUMS` accompanies the downloads.

## 本版更新

新增分析页，支持日期、项目、模型、主对话 / subagent / 合并范围筛选，并提供活动热图、日周月明细、模型和工具排行、本机预算提醒，以及四种格式的筛选报告导出。桌面版通过系统保存窗口保存文件。

会话搜索覆盖 ID、项目、路径、分支与每条消息前 200 字的索引预览。所有分析日期使用 UTC，周从周一开始。预算和成本是 API 等价估算，不代表订阅账单或官方剩余额度。

后续更新继续递增补丁版本号（v0.2.2、v0.2.3 等）。
