# Turnflare v0.1.0

Explore where your Claude Code tokens go, from projects to individual turns and subagents.

## Install

Requires Node.js 22 or 24.

```bash
npm install --global https://github.com/Naloam/turnflare/releases/download/v0.1.0/turnflare-0.1.0.tgz
turnflare demo
# Index your own local Claude Code history:
turnflare start
```

The demo uses nine synthetic sessions and an in-memory database. It never reads your Claude history.
The installable package includes the compiled CLI, dashboard and database migrations. Third-party runtime dependencies are installed by npm; SQLite may need a C++ toolchain if a prebuilt binary is unavailable.

## Included

- A local dashboard with persistent English/Chinese language and light/dark theme choices.
- Project comparisons, cost trends, model distribution, turn timelines and tool calls.
- Separate main conversation and subagent activity, with server-side chain filtering and 500-turn pages.
- Incremental indexing and optional dashboard refresh every ten seconds.
- Terminal reports and JSON, Markdown, CSV and self-contained HTML exports.
- Shared type contracts and public package interfaces across the monorepo.
- Isolated demo data, browser tests and installation verification.

## Scope

Claude Code logs only. Costs are API-equivalent estimates from bundled pricing, not subscription charges or an invoice. Unknown models are marked as unpriced. Main conversation and subagent totals are separate. Detailed CLI reports and API diagnostics currently use Chinese.

No API key or telemetry. Keep the normal server on the loopback interface: it has no authentication and can display conversation previews and local paths.

SHA256SUMS accompanies the installable archive.
