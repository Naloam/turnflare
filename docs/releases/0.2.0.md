# Turnflare v0.2.0 — Windows and macOS apps

Download, open, and explore your Claude Code history. **No Node.js, npm, terminal commands or API key required.**

## Choose a download

| Your computer | File | How to use |
| --- | --- | --- |
| Windows 10/11, x64 | `Turnflare-0.2.0-windows-x64-setup.exe` | Open the installer. A Start menu entry and desktop shortcut are created. |
| Windows 10/11, x64, no installation | `Turnflare-0.2.0-windows-x64-portable.exe` | Open the file directly. |
| Mac, Apple Silicon (M1/M2/M3/M4 or newer) | `Turnflare-0.2.0-mac-arm64.dmg` | Open and drag Turnflare into Applications. |
| Mac, Intel | `Turnflare-0.2.0-mac-x64.dmg` | Open and drag Turnflare into Applications. |

macOS 13 or later is required. Mac ZIP archives are also available. The `.tgz` is the optional command-line distribution, not the desktop app.

## First launch

The app automatically looks in your home directory's `.claude/projects` folder. If your history is elsewhere, use **Choose history folder / 选择日志目录**. The selected directory is remembered. Use **Try examples / 体验示例** to explore nine synthetic sessions without reading your history.

Language and theme choices persist. Indexing and refresh run every ten seconds. Closing the application stops indexing. Each selected history folder has a separate local index; example data uses disposable memory storage.

## Signing status

These initial builds are **not signed with a trusted developer certificate**. Mac apps have an ad-hoc signature and have not been notarized by Apple. Windows may display SmartScreen; macOS may require confirming the app in **System Settings → Privacy & Security → Open Anyway** after the first attempt. Follow [Apple's opening guidance](https://support.apple.com/102445). Do not disable system-wide protections.

Fully eliminating those first-launch checks needs developer signing certificates and macOS notarization, which are not configured for this release.

## Verification and privacy

The packaged applications are launched on native Windows x64, macOS arm64 and macOS x64 runners, including the app copied from the DMG and the installed Windows app. The checks exercise bundled SQLite, migrations, assets, session detail, example mode and preference persistence.

The desktop uses a private application protocol and does not listen on a local network port. Its renderer is sandboxed and has no Node.js access. No session uploads or telemetry. Cost amounts remain API-equivalent estimates, not subscription bills. **SHA256SUMS** covers all downloads.
